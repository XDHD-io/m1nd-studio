Off-grid configuration

GROW01-OG · off-grid spec

The iDOO 12-pod runs at 12V/3A/36W. The GROW01-OG-spec-v0.2 documents the off-grid configuration: a $40 third-party Ryobi-compatible AC inverter (or the studio's Ryobi 800W inverter) runs the iDOO continuously off Ryobi One+ 18V batteries with solar supplementation. The system runs indefinitely with appropriate solar input — the studio has validated this through actual operation.

This is the spec that opens cabin / RV / Hako / off-grid deployment for the GROW catalogue. Customers in remote locations can run the iDOO without grid power.
